Pedidos

Ao finalizar um pedido, o site envia à API da Joinha Sorvetes os dados necessários para registrar e acompanhar a compra: nome, itens, quantidades, preços, total, tipo de recebimento, data e status. Se escolher delivery, também são registrados o CEP e o endereço informado. Usamos esses dados para preparar, entregar ou disponibilizar o pedido, responder dúvidas e manter o histórico operacional da loja. O painel é acessado por pessoas autorizadas da loja.

Depois do registro, o site abre o WhatsApp com uma mensagem pronta para você enviar. Os dados incluídos nessa mensagem serão recebidos pelo WhatsApp e tratados conforme as políticas do próprio serviço. O registro no painel e o envio da mensagem pelo WhatsApp são etapas diferentes.

Consulta de CEP

Quando você informa um CEP no checkout, o site pode consultar o serviço ViaCEP para preencher rua e bairro. O CEP é enviado ao ViaCEP para essa consulta. A taxa de entrega é calculada conforme as regras de bairros configuradas pela loja; bairros não cadastrados podem ter o frete combinado pelo WhatsApp.

Carrinho no seu navegador

Os itens escolhidos e alguns dados de preenchimento do checkout ficam salvos no armazenamento local do navegador para que não se percam ao trocar de página. Esse armazenamento é diferente do registro do pedido no servidor. Você pode esvaziar o carrinho e limpar os dados do site no navegador para remover os dados locais.

Retenção e solicitações

Os registros de pedidos são mantidos pelo tempo necessário para atender a compra, organizar a operação da loja e cumprir obrigações legais aplicáveis. Para pedir acesso, correção ou eliminação de dados, ou esclarecer dúvidas sobre o tratamento, use o contato de privacidade informado nesta página. Alguns registros podem precisar ser mantidos quando houver obrigação legal.

Cookies de estatística

Só se você aceitar, usamos o Google Analytics para medir visitas: páginas acessadas, tipo de aparelho e origem aproximada. Esses dados são tratados pelo Google. Você pode mudar sua escolha a qualquer momento em “Preferências de cookies”, no rodapé.

Seus direitos

Pela Lei Geral de Proteção de Dados (Lei 13.709/2018), você pode pedir confirmação de tratamento, acesso, correção, eliminação de dados e revogação de consentimento. Escreva para o e-mail acima.

Mudanças nesta política

Se algo mudar, atualizamos esta página e a data acima.
